Recursive Ray Transport: Implements a recursive castRay function to simulate multi-bounce light behavior, including reflection and refraction based on Snell’s Law and Fresnel equations.

Geometric Primitives: Supports a variety of shapes through analytical intersection logic, including Spheres, Oriented Bounding Boxes (OBB), Cylinders, and Triangle Meshes.

Physically-Based Shading: Features a material system that supports Diffuse and Glossy surfaces using the Phong illumination model, as well as transparent dielectrics.

High-Fidelity Rendering: Includes a stochastic Anti-Aliasing system that uses 16 samples per pixel to reduce jagged edges and improve image smoothness.

Custom Math Library: Built on a custom-coded linear algebra framework for 3D vector operations, dot/cross products, and coordinate space transformations.
